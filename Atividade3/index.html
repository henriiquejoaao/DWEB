O que é um Framework?

Um framework é como um molde ou uma caixa de ferramentas para programadores. Em vez de escrevermos todo o código do zero para criar um site ou aplicação, o framework já nos dá uma estrutura básica pronta.

Isso ajuda-nos a poupar tempo, evita que cometamos erros básicos de segurança e mantém o código mais organizado.

Frameworks Front-end Populares

Estes frameworks ajudam a construir a parte visual do site, ou seja, aquilo com que o utilizador interage diretamente no ecrã:

  • React: Criado pelo Facebook (Meta). Muito usado para criar interfaces rápidas e dinâmicas. (Site oficial)
  • Vue.js: É bastante famoso por ser mais fácil de aprender para quem está a começar no desenvolvimento Web. (Site oficial)
  • Angular: Criado pela Google. É muito completo e geralmente usado em projetos empresariais grandes. (Site oficial)

Frameworks Back-end Populares

Estes lidam com os bastidores: a lógica do servidor, acesso às bases de dados e segurança da informação:

  1. Laravel (PHP): Um dos mais usados na linguagem PHP por tornar a escrita do código muito elegante e simples.
  2. Express.js (Node.js): Muito usado hoje em dia porque permite aos programadores usar JavaScript também no servidor.
  3. Spring Boot (Java): A escolha principal para quem trabalha com Java, muito presente no mercado de trabalho tradicional.

Principais Vantagens

Por que motivo usamos frameworks em vez de programar tudo com HTML, CSS e JS puros?

  • Rapidez: O projeto fica pronto muito mais depressa.
  • Organização: Obrigam-nos a usar boas práticas (como a arquitetura MVC).
  • Comunidade: Se tivermos uma dúvida, é fácil encontrar ajuda online.
  • Segurança: Muitas falhas comuns já vêm resolvidas pelo próprio framework.
